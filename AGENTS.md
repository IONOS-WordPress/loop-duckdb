# AGENTS

This project uses DuckDB and Bash scripts to automate data analysis and report generation. 

## Report Generation

- **generate-report-parts/**  
  Contains modular Bash scripts for generating specific sections of the report (e.g., plugins, themes, logins, PHP versions).

## Data directories

- **s3/**  
  Directory containing downloaded JSON data files from S3.

- **duckdb/ui/**  
  Directory containing exported notebook files and schema.
